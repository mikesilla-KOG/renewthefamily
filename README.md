# Renew the Family

Static single-page website for **Renew the Family** with:

- a warm, family-focused landing page
- responsive sections on family stability, fertility trends, and practical renewal
- Chart.js-powered data visualizations with graceful local fallbacks
- a localStorage-backed demo discussion board

## Local preview

```bash
cd /tmp/workspace/mikesilla-KOG/renewthefamily
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173/index.html`.
